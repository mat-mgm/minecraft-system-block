## Installation & Deployment Protocol
### *(How to Welcome Unrestricted Binaries Into Your Facility)*

Installing the System Block is remarkably straightforward, requiring only a modest suspension of standard IT security guidelines:

### Phase 1: Prerequisite Verification
Before inviting host shell commands into your game loop, confirm your environment meets the minimum thresholds of reckless innovation:
- **Minecraft**: Version `26.3` (or compatible).
- **Fabric Loader**: Version `>= 0.19.0`.
- **Fabric API**: Installed in your `mods/` folder (our network streaming payloads need someone to talk to).
- **Java Runtime**: OpenJDK `>= 25` (modern exploits demand modern garbage collectors).

### Phase 2: Procuring the Artifact
Download the latest pre-compiled binary straight from the laboratory dispensary:
- 📂 **Direct Release**: [`release/minecraft-system-block-1.0.0.jar`](release/minecraft-system-block-1.0.0.jar)
- **SHA-256 Digest**: `4f9024aa10d3568e15ea1f40379525e485dc2f1e24daaad5c896c376d11911f1`

### Phase 3: Deployment Topology

#### Option A: Client Installation (Singleplayer / Local Testing)
1. Navigate to your Minecraft profile directory (`%appdata%\.minecraft` on Windows, `~/.minecraft` on Linux/macOS).
2. Locate (or create) the `mods/` subdirectory.
3. Drop `minecraft-system-block-1.0.0.jar` into `mods/`.
4. Fire up your launcher with your Fabric 26.3 profile.
5. Create a world, open the **Redstone Blocks** creative tab, place the System Block, and revel in your newly established direct pipe to `/bin/bash`.

#### Option B: Server Installation (Multiplayer Collaboration)
1. Stop your dedicated server (recommended, though hot-dropping jars builds character).
2. Drop `minecraft-system-block-1.0.0.jar` into the server's root `mods/` directory.
3. Ensure every connecting player also has the mod installed in their client `mods/` folder (so their client can render the 3D crystal and open the interactive matrix terminal).
4. Start the server. 
5. Grant OP (`/op <player>`) only to players you would trust with your online banking passwords, house keys, and production database credentials. Non-OP players can still look at the block with awe, but cannot edit commands or spawn processes.
